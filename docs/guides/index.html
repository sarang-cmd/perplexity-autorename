■ WHAT IS AUTO-RENAME FOR PERPLEXITY? MIT OPEN SOURCE

Auto-Rename for Perplexity is a free, open-source Chrome/Chromium Manifest V3 extension (perplexity-autorename.vercel.app · GitHub) that watches the first answer stream on every brand-new perplexity.ai thread and automatically saves a clean 3–7 word summary title via Perplexity’s native title API—supporting 10 LLM providers plus a zero-key offline mode.
