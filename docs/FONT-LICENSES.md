# Bundled Pixel Font Licenses

This extension bundles two open-source pixel font families locally inside `extension/fonts/` so zero external font CDN calls are made at runtime:

1. **Silkscreen** (`Silkscreen-Regular.woff2`, `Silkscreen-Bold.woff2`)
   - Copyright (c) 2022 Jason Kottke (https://github.com/kottke/silkscreen)
   - Licensed under the **SIL Open Font License, Version 1.1** (https://openfontlicense.org)

2. **Pixelify Sans** (`PixelifySans-Regular.woff2`, `PixelifySans-SemiBold.woff2`, `PixelifySans-Bold.woff2`)
   - Copyright (c) 2023 Stefie Justprince (https://github.com/eifetx/Pixelify-Sans)
   - Licensed under the **SIL Open Font License, Version 1.1** (https://openfontlicense.org)
