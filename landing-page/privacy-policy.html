PRIVACY POLICY — AUTO-RENAME FOR PERPLEXITY

Effective Date: October 24, 2026

1. OVERVIEW & SINGLE PURPOSE

Auto-Rename for Perplexity is a browser extension whose single purpose is to automatically generate and save a concise 3–7 word thread title on https://www.perplexity.ai once the first answer in a brand-new thread finishes streaming.

The developer operates no backend servers, databases, analytics, or telemetry. All operations happen locally in your browser and directly between your browser and the LLM API provider you choose to configure.

2. DATA ACCESSED AND PROCESSED

  • First Question & Answer Excerpt (Website Content): When enabled on a new Perplexity thread, up to the first 600 characters of your initial question and up to 1,200 characters of the completed first answer are read in memory and sent directly over HTTPS to your configured LLM API endpoint solely to generate a 3–7 word title. Follow-up questions in existing threads are skipped. If no API key is configured, a local keyword heuristic generates the title entirely offline in your browser.
  • Same-Origin Perplexity Identifiers: Thread context_uuid, read_write_token, and your Perplexity user.id (fetched same-origin from /api/auth/session) are used exclusively to send the rename request to https://www.perplexity.ai/rest/thread/set_thread_title. Session tokens, cookies, and account IDs are never stored persistently or sent outside www.perplexity.ai.
  • Local Storage (chrome.storage.local): Your selected provider/model preferences, API key (accessible only to the extension’s background service worker), and up to 200 recent thread rename titles are stored locally on your device.

3. DATA SHARING & THIRD PARTIES

The developer never collects, views, sells, or shares user data. Excerpts of the first Q&A are transmitted only to the LLM provider endpoint you explicitly configure (e.g., Groq, OpenRouter, Gemini, OpenAI, Anthropic, Mistral, Cerebras, OpenCode Zen, Sarvam, or your custom endpoint), governed by that provider’s terms and privacy policy.

4. CHROME WEB STORE LIMITED USE COMPLIANCE

Use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is never used for advertising, profiling, or unrelated purposes.

5. USER CONTROL & DELETION

You can disable automatic renaming at any time from the toolbar popup, delete stored API keys via Clear Key, erase rename history via Clear History in Extension Settings, or remove all local data permanently by uninstalling the extension.
