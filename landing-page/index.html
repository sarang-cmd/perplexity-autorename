3-WORLD MV3 STREAM ARCHITECTURE

Zero brittle DOM scraping and zero API-key exposure. Auto-Rename clones Perplexity’s SSE stream at the network boundary via Response.body.tee() while locking your API key strictly inside the background Service Worker.

WORLD 1 · MAIN

STREAM TEE & RENAME BRIDGE

page.js wraps window.fetch at document_start, splits /rest/sse/perplexity_ask via response.body.tee() so Perplexity’s UI streams at native speed, and submits same-origin set_thread_title (HTTP 204). Has zero access to storage or API keys.

WORLD 2 · ISOLATED

DECISION GATE & SHADOW HUD

content.js evaluates shouldRename() (skipping follow-ups, manual edits, and regex exclusions), renders the isolated Shadow-DOM pixel HUD, and coordinates bounded 600ms / 1800ms retry backoff on transient 5xx errors.

WORLD 3 · SERVICE WORKER

EXCLUSIVE API KEY VAULT

background.js is the only module in the codebase that calls getApiKey() (enforced by automated tests). Calls your chosen LLM with a 10s AbortController, strips <think> tags, and falls back cleanly to heuristicTitle().

SRC/PAGE/INJECT.JS — NON-DESTRUCTIVE STREAM CLONING 
const response = await originalFetch.apply(this, args);

if (isAskSseRequest && response.ok && response.body?.tee) {
  const [pageBranch, observerBranch] = response.body.tee();

  // Branch 2 assembles SSE frames asynchronously without touching UI rendering
  observeAskStream(observerBranch, requestMeta);

  // Branch 1 returns immediately to Perplexity's React app at native speed
  return new Response(pageBranch, {
    status: response.status,
    statusText: response.statusText,
    headers: response.headers,
  });
}

Questions & Answers

FREQUENTLY ASKED QUESTIONS

DOES THIS CHANGE PERPLEXITY.AI’S FONTS, THEME, OR PAGE LAYOUT?
No. Perplexity’s website layout, fonts, and CSS remain 100% untouched. Only the extension’s own toolbar popup, settings page, and isolated Shadow-DOM bottom-right status toast use the retro pixel HUD theme—and the toast can be disabled anytime with one click.
WHERE IS MY LLM API KEY STORED, AND CAN WEBSITES READ IT?
Your API key is stored locally on your device in chrome.storage.local and read exclusively inside the extension’s background MV3 Service Worker (src/background/service-worker.js). Neither perplexity.ai nor content scripts nor even the popup DOM ever read back the raw key string. Zero developer servers or analytics exist.
CAN I USE IT COMPLETELY FREE WITHOUT AN API KEY?
Yes! Out of the box with no API key saved, Auto-Rename uses its built-in offline keyword heuristic (heuristicTitle()) to generate clean 3–7 word titles locally with zero network requests. You can also use free-tier keys from Groq, Google AI Studio (Gemini), OpenRouter :free models, or a local Ollama server.
WILL IT OVERWRITE TITLES I RENAME MANUALLY OR ON FOLLOW-UP QUESTIONS?
Never. Follow-up messages and related-query clicks are skipped automatically via last_backend_uuid and is_related_query. And if you manually rename a thread in Perplexity’s sidebar, the extension detects that request and locks out auto-renaming for that thread permanently.
