To install Auto-Rename for Perplexity without the Chrome Web Store, download auto-rename-for-perplexity-v0.2.0.zip from perplexity-autorename.vercel.app, extract the ZIP to a permanent folder, open chrome://extensions (or brave://extensions, arc://extensions, edge://extensions), turn on Developer mode, click Load unpacked, and select the extracted folder containing manifest.json.

Browser-by-Browser Extensions URL & Developer Mode Location

Every Chromium-based desktop browser uses the exact same Manifest V3 extension engine under the hood—only the settings URL and toggle placement differ slightly:

Browser Extensions URL Where to Toggle Developer Mode
Google Chrome chrome://extensions Top-right toggle switch → click Load unpacked (top-left).
Brave Browser brave://extensions Top-right toggle switch → click Load unpacked (top-left).
Arc Browser arc://extensions Top-right toggle switch (or Cmd/Ctrl + T → Manage Extensions) → Load unpacked.
Microsoft Edge edge://extensions Left sidebar toggle labeled Developer mode → click Load unpacked.
Vivaldi / Opera vivaldi://extensions Top-right Developer mode toggle → Load unpacked.

Important Tip: Keep the Unzipped Folder in a Permanent Spot

When you load an unpacked extension in Chromium, the browser reads files from that directory on launch rather than copying them into an internal .crx archive. Before clicking Load unpacked, move the unzipped folder out of Downloads into a permanent location like ~/Extensions/auto-rename-for-perplexity or C:\Extensions\auto-rename-for-perplexity so you don’t accidentally delete it later.

Prefer Building from Source?

If you want to audit every line of code and compile the 5 bundles yourself with esbuild (Node.js 20+), clone the MIT repository directly:

TERMINAL 
git clone https://github.com/sarang-cmd/perplexity-autorename.git
cd perplexity-autorename
npm install
npm run build && npm test

Then point Load unpacked at the compiled extension/ subdirectory inside the repo.

Auditable Permissions: Why Minimal MV3 Permissions Matter

Many third-party AI browser extensions request blanket <all_urls> access on install. Auto-Rename for Perplexity requests only storage and https://www.perplexity.ai/* at install time. Network access to your chosen LLM endpoint (for example https://api.groq.com/*) uses Chrome’s optional_host_permissions and is requested only for the single provider you actively select.

Frequently Asked Questions

IS IT SAFE TO INSTALL AN UNPACKED CHROME EXTENSION FROM GITHUB?
Unpacked extensions let you read every file directly before loading. Auto-Rename for Perplexity has zero external runtime scripts, zero analytics/telemetry servers, runs 53 automated tests, and isolates API keys strictly inside the MV3 Service Worker.
HOW DO I UPDATE THE UNPACKED EXTENSION WHEN A NEW VERSION COMES OUT?
Extract the new release files over your existing folder (or git pull && npm run build if cloned from GitHub) and click the Reload icon on chrome://extensions. Your saved settings, API keys, and rename history in chrome.storage.local are preserved.
DO I NEED TO RELOAD OPEN PERPLEXITY.AI TABS RIGHT AFTER INSTALLING?
Yes—refresh any already-open perplexity.ai tab once after clicking Load unpacked so Chrome attaches the MV3 content and page scripts to that tab.
